# 웹 봇 레이팅 (규칙·인원별 실측)

- 날짜: 2026-11-21
- CI 실행: https://github.com/lowqen/hoola-ai/actions/runs/44854711531 (`gh workflow run ci.yml -f experiment=rating -f size=full`)
  - `hoola-lab --only R --players N --deals D --search-deals S --preset ...` (시작 시드 1,000,000). 코드: `crates/hoola-lab/src/rating.rs`
  - 딜 수: 2인 50,000(탐색 봇이 낀 쌍 6,000), 3인 8,000(1,000), 4인 4,000(600), 5인 3,000(600)
- 대상: 웹 연습장 봇 7종(`web/src/lib/play/bots.ts`와 같은 사양). 탐색 봇은 `search:k=128` (아래 "R1 이후 재측정"은 R1 최종 사양)
- **시드 고정 교차 대국**: 봇 n개를 고른 모든 테이블에서, 같은 딜(시드·선)을 좌석 배치만 바꿔 여러 번 둔다. 2인은 자리를 바꿔 2판, n인은 회전 n가지 × 방향 2가지로 2n판(3인은 모든 순열). 같은 카드를 모든 봇이 같은 자리에서 한 번씩 받으므로 카드 운이 상쇄된다.
- **레이팅**: 판마다 "둘 중 한쪽만 이긴" 쌍을 1승으로 세어 Bradley–Terry 최대우도로 맞췄다. 친구모델 = 1000. 2인에서는 보통의 Elo와 같다(+100점 ≈ 맞대결 64%). ±는 딜 20구간 잭나이프 95% 반폭(친구모델 기준이라 친구모델은 0).
- **기대점수**: 쌍 비교에서 단독 우위 1, 동률(둘 다 승·둘 다 패) 0.5의 평균.
- **점수차**: 판이 끝났을 때 (상대 손패 점수 − 내 손패 점수)의 평균. 이 룰은 단판 승패라 정산 점수가 없으므로, "얼마나 크게 이기고 지는가"의 대리 지표다.
- **승률** 열은 그 봇이 앉은 모든 판의 평균이다. 탐색 봇이 낀 쌍은 딜 수가 적어서 봇마다 상대 구성 비중이 조금 다르다. 봇끼리 비교는 레이팅으로 한다.
